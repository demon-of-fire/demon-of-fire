Game Mods

Modifications that make popular games genuinely playable by blind and visually impaired players. Every mod speaks through NVDA / Tolk, plays spatial audio cues, and keeps the game fair — features that preserve the experience instead of auto-playing it for you.

FC 26 Accessibility Mod

EA Sports FC 26 · Python
Download available

A Vision AI screen reader for EA Sports FC 26. Uses Florence-2 + EasyOCR to describe the match state in real time — fully on-device, no cloud, no latency. v1.1.0: screen-change detection for smooth performance, match score/clock reading (F6), goal and half-time announcements.

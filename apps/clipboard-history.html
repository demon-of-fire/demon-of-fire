Clipboard History

A blazing fast, secure clipboard history manager written in Rust. Copy anything, find it instantly with regex search, and reuse it with a single keystroke — encrypted at rest and fully keyboard-navigable.

Windows / Linux Rust AES-GCM Encryption Regex Search Open Source · MIT

Overview

Clipboard History remembers everything you copy so you never lose a snippet again. Built in Rust for speed and safety, it keeps your clipboard history encrypted on disk and lets you navigate it entirely from the keyboard.

Key Features

  • Global Hotkeys: Open history, paste last item, and search from any application.
  • AES-GCM Encrypted Persistence: Your clipboard history is stored securely at rest.
  • QR Code Extraction: Detects and extracts QR codes from copied images.
  • Regex Searching: Find any item with powerful pattern matching.
  • Keyboard Navigation: Full arrow-key workflow — no mouse required.
  • Cross-Platform: Runs on Windows and Linux.

Keyboard Shortcuts

  • Ctrl + Alt + V — Open clipboard history
  • Ctrl + Alt + Shift + V — Paste the most recent item
  • / — Focus search box
  • Enter — Copy and paste the selected item

Accessible Calculator

Windows

A simple, fast desktop calculator designed for NVDA screen reader users. Every key, result, and operation is announced — nothing hidden behind the mouse.

Windows NVDA Compatible Keyboard First

About

Accessible Calculator is a desktop calculator that treats the screen reader as a first-class citizen. Every key press, every result, and every operation is spoken — and you can also type calculations in natural language instead of hunting for buttons.

Download

Download the installer from GitHub Releases, run it, and follow the setup wizard prompts.

Features

  • Every key, result, and operation announced by your screen reader
  • Natural language input — type "what is 15 percent of 200" and get an answer
  • Fast and lightweight, no installation dependencies
  • Designed and tested with NVDA

Getting the Source

The source package is attached to the same release as the installer — look for AccessableCalculator-source.zip on the release page.

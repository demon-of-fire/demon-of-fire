Access Overlay

A universal screen-reader overlay, document reader, and OCR game scanner for Windows. Captures any foreground app, website, or game and renders it as clean, readable text with NVDA speech and customizable visual themes.

Windows 10 / 11 .NET 8 · WPF · C# NVDA / SAPI Speech OCR Engine Open Source · MIT

Overview

Many Windows applications, legacy tools, and game menus do not expose native accessibility trees or clean text hierarchies. Access Overlay bridges this gap by providing an always-available universal reader that can capture and normalize any foreground application, scan in-game menus via OCR, or load web articles into a clean reading view.

Key Features

  • Foreground App Capture (Ctrl+Alt+A): Inspects UI Automation elements of the active window and reorganizes them into a structured, readable document.
  • OCR Game Scanner (Ctrl+Alt+G): Reads on-screen menus, dialogs, and HUD text in video games across Unreal Engine, Frostbite, Source, Unity, and custom engines.
  • Integrated Accessible Web Browser: Built-in WebView2 browser with article text extraction and automated speech after page loads.
  • Floating Reader Window: Customizable overlay with adjustable font sizes (12px - 48px), contrast themes (Dark, Light, High Contrast), and opacity slider.
  • Dual Speech Routing: Seamlessly speaks through NVDA via the controller client or falls back to Windows SAPI speech.
  • Auto-Follow Mode: Dynamically updates the reading buffer as you switch between applications.

Keyboard Shortcuts

  • Ctrl + Alt + A — Capture active foreground window and speak text
  • Ctrl + Alt + G — Scan game screen with OCR
  • F9 / F10 / F11 — Audio and playback controls

Download

Download the latest AccessOverlaySetup.exe installer from the GitHub Releases page . Run the installer to set up Access Overlay on your Windows PC.

Open Source & Development

Access Overlay is 100% free and open-source under the MIT licence. You can inspect the source code, contribute, or build it yourself using the .NET 8 SDK.

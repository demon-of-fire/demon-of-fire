FC 26 Accessibility Mod

EA Sports FC 26 · Python

A Vision AI screen reader for EA Sports FC 26. Florence-2 and EasyOCR describe the match state in real time — fully on-device, no cloud, no latency.

Vision AI On-Device Screen Reader Fair Play

About

The FC 26 Accessibility Mod watches the game for you and speaks what matters: the score, the clock, goals, half-time — all read in real time by local AI. Nothing leaves your PC.

How It Works

  • Florence-2 — a vision AI model running locally on CPU that understands the match state
  • EasyOCR — local neural OCR for reading text on screen
  • Fully on-device — no cloud, no API key, no latency

What's New in v1.1.0

  • Screen-change detection for smooth performance
  • Match score and clock reading (F6)
  • Goal and half-time announcements

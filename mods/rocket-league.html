Rocket League Accessibility Mod

Rocket League · Python

Accessibility mod for visually impaired Rocket League players. Local AI-powered screen reading and spatial audio ball tracking so you always know where the ball and your teammates are — no cloud, no API key, fully private.

Vision AI Spatial Audio On-Device NVDA Compatible

About

The Rocket League Accessibility Mod uses local AI (Florence-2 + EasyOCR) to read the game screen and give you audio feedback. Florence-2 — a 230M parameter vision AI — runs locally on CPU for smart reads like boost, score, and ball detection, while EasyOCR handles bulk text reads like menus and the full screen.

Hotkeys

Key Action
F1Score and time remaining
F2Boost amount
F3Read menus
F4Read full screen
F5Audio test beep
F6Toggle ball tracker
F8Toggle auto-reader
F9Force borderless windowed mode

How It Works

  • Ball tracker (F6) — spatial audio beeps show ball position with stereo panning for left/right and pitch for height
  • Auto-reader (F8) — automatically reads the selected menu item as you navigate
  • NVDA integration — speech via NVDA, falling back to Windows SAPI if NVDA is not running
  • Viewport auto-detection — works on any monitor resolution and handles black bars automatically

Setup

  1. Install Python 3.10+ (64-bit)
  2. Install dependencies: pip install -r requirements.txt
  3. Run the mod: python main.py

The first run downloads the AI models (~500 MB total). They are cached locally afterwards. Optional: build a standalone exe with python -m PyInstaller RLAccessibilityMod.spec --noconfirm.

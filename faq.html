General

Are these apps and mods really free?

Yes. Every project is 100% free and open source under the MIT licence. There are no paid tiers, no premium features, and no ads.

Do I need to create an account?

No — never. There are no accounts, logins, or user profiles anywhere on this website or in these apps. See the privacy policy for details.

Do the apps work with NVDA?

Yes. NVDA is the primary screen reader supported across the apps and mods, with Windows SAPI as a built-in fallback for speech.

How do I get help or report a bug?

Join the Discord server for community support, or open an issue on the relevant GitHub repository.

Among Us Accessibility Mod

How do I install the mod?

Download the folder package (it includes BepInEx 6, so nothing else to install), open the zip, and copy everything inside the AmongUsAccessibilityMod folder into your Among Us game folder — winhttp.dll must land next to Among Us.exe. Launch the game once, close it, then launch again. If you already have BepInEx 6 installed, just copy Among.Us.Accessibility.Mod.dll into BepInEx/plugins instead. Full instructions are on the GitHub repository.

Does the mod require NVDA to be installed?

The mod is designed around NVDA speech, but it also provides its own spatial audio cues, so you can still orient yourself by ear even without a screen reader.

Does the mod change the game or give an unfair advantage?

No. Gameplay and the alibi value of visual tasks are fully preserved — confirmation of tasks stays manual, and the mod only reads out what is already on screen.

How do I learn the controls?

Press F1 at any time and the mod speaks the full keybind list. The most useful keys: H status read-out, B sabotage map (or task list as crewmate), V nearest vent / vent navigation / spectate while dead, M pause menu, F2 mute, and Ctrl+, / Ctrl+. to repeat the previous or next announcement.

Can I turn off specific announcements?

Yes. Every announcement type has its own toggle — 19 in total — in BepInEx/config/greenbean.amongusaccessibilitymod.cfg (section [Announcements]). For example you can keep sabotage and kill-cooldown callouts but silence the lobby readout. Changes apply the next time the game loads.

Can I mute the mod temporarily during a game?

Press F2 to mute all announcements for 30 seconds; press F2 again to unmute immediately.

Does the mod work when I'm dead?

Yes. The vanilla game has no spectate feature on PC, so the mod adds one: while dead, press V to cycle through the living players and follow them, hearing who you are watching and whenever they change rooms.

How do I update the mod?

Download the latest folder package and copy the files over your game folder the same way as the first install. Your settings in BepInEx/config are kept.

The mod isn't loading or nothing is spoken — what do I do?

Delete the BepInEx folder from your Among Us game folder and repeat the installation steps (this clears the generated interop data that occasionally goes stale). If Windows SmartScreen blocks the first launch, click "More info" then "Run anyway" — this is normal for unsigned mods.

FC 26 & Rocket League Mods

What do the football mods need to run?

A Windows PC with a reasonably modern GPU, because the AI (Florence-2 + EasyOCR) runs fully on-device. Everything is processed locally — no cloud, no internet needed while playing.

What does the FC 26 mod read out?

It describes the match state in real time — including the score and clock (press F6), goal and half-time announcements, and on-screen menus.

How does the Rocket League ball tracking work?

A local AI reads the screen and converts the ball's position into spatial audio cues, so you always know where the ball and your teammates are by ear.

Access Overlay

What are the main shortcuts?

Ctrl + Alt + A captures the active window as readable text, Ctrl + Alt + G scans the game screen with OCR, and F9 / F10 / F11 control playback.

Which games does the OCR scanner work with?

It reads on-screen text across Unreal Engine, Frostbite, Source, Unity, and custom engines — any game that renders text to the screen.

AI Features & Privacy

Which apps use AI, and where does it run?

Access Recorder transcribes audio locally with Whisper — nothing leaves your PC. Nova Voice Assistant uses Google Gemini for conversation; the content you ask about is sent to Google only when you use those features.

Do I need a Google Gemini API key?

Only for Gemini-powered features, and it's optional. You provide your own key in the app's settings. Your key is stored only on your device — nobody else can see it, and if billing applies it happens directly between you and Google on your own Google account. See the privacy policy for the full details.

Is my audio or screen recorded or uploaded?

No. Microphone capture happens only while you actively use a voice feature, and screen analysis in the game mods runs entirely on-device. Nothing is uploaded to Demon of Fire or any other server.

Supported Platforms & Requirements

Which Windows versions are supported?

The desktop apps target Windows 10 and Windows 11 (64-bit). Clipboard History additionally runs on Linux. The game mods run on Windows because they hook into the local game process and screen.

Are the apps available for macOS or Linux?

Most apps are Windows-only because they integrate with Windows UI Automation and screen readers like NVDA. Clipboard History is the exception and runs on both Windows and Linux. The Misc Tools projects (revision hub, Agony Report, Minecraft site) are websites that work in any modern browser.

Do I need to install runtimes like .NET or Python?

Installers bundle what they need. Access Overlay ships a .NET 8 installer, and the media/AI apps are packaged as standalone executables. The Rocket League mod is run from Python source, so it needs Python 3.10+ and a pip install -r requirements.txt.

Will Windows SmartScreen block the download?

Possibly, on first launch — these are small open-source projects without a paid code-signing certificate. Click "More info" then "Run anyway". This is normal for independent software and does not mean the file is unsafe. Every release is open source so you can verify or build it yourself.

Can the apps run on a low-spec PC?

The apps are lightweight. The only heavy requirements come from the AI-powered tools: the FC 26 and Rocket League mods run local vision models, so they benefit from a modern multi-core CPU (and a GPU helps the football mod), while the other apps run comfortably on modest hardware.

Do I need a screen reader to use the apps?

No. The apps are fully usable with the mouse and keyboard and have high-contrast themes and large text. Screen readers like NVDA simply make them faster and friendlier for blind and low-vision users — the apps are designed so everyone can use them.

Installation & Updates

How do I install an app?

Download the installer (or .zip) from the project's GitHub Releases page, run it, and follow the prompts. Most installers need only a standard user account — no admin rights required.

How do I update an app?

Download the latest release and install it over the top — your settings are preserved. The homepage "Latest Releases" section and the changelog always show the newest version of every project.

How do I uninstall an app?

Use Windows Settings → Apps → Installed apps (or the classic Programs and Features), select the app, and choose Uninstall. Portable .zip builds (like Accessible Studio) can simply be deleted from their folder.

How often are the projects updated?

There is no fixed schedule — updates land whenever a bug is fixed or a feature is ready. Major apps get regular attention; you can watch the changelog or the Discord for release announcements.

Access Overlay

What is Access Overlay for?

It is a universal reader for anything on screen. Capture the active window and hear it as clean, structured text, scan game menus with OCR, or load web articles into a distraction-free reading view — all spoken through NVDA.

How does the OCR game scanner work?

Press Ctrl + Alt + G and Access Overlay takes a screenshot of the game, runs a local OCR engine over the text, and reads it back. It works across Unreal Engine, Frostbite, Source, Unity, and custom engines — anywhere text is drawn to the screen.

Can it read web pages too?

Yes. The built-in WebView2 browser extracts article text and speaks it automatically after a page loads, so long articles are readable without fighting a busy layout.

Access Recorder

What does Access Recorder do?

It is an audio recording studio with on-device Whisper transcription. Record, import beats, monitor live input, and turn recordings into searchable text — all fully keyboard- and screen-reader accessible.

Is the transcription really local?

Yes. Whisper runs entirely on your PC — nothing is uploaded. Your recordings and their transcripts never leave your machine.

What are the main shortcuts?

Ctrl + Shift + R start/stop recording, Ctrl + Shift + P pause/resume, Ctrl + T transcribe, and Ctrl + O open a recording.

Accessible Studio

What is Accessible Studio?

An all-in-one creative suite: a timeline video editor, a photo editor, and a file converter, built keyboard-first with screen-reader announcements for every action.

Do I need an API key for the AI features?

No. Built-in keyword matching understands commands like "trim the first 5 seconds" without any key. Connecting a free Google Gemini key in Settings unlocks the full natural-language assistant, photo vision, and complex multi-step editing.

What file formats can it convert?

Video (MP4, AVI, MKV, MOV, WebM), audio (MP3, WAV, FLAC, OGG, AAC), images (PNG, JPG, WebP, BMP, GIF, TIFF), and documents (DOCX↔TXT, DOCX→HTML, TXT→HTML).

Is there a portable version?

Yes — download the .zip from the releases page, extract it, and run Accessible Studio.exe. No installation required.

Accessible Media Player

What can the media player do?

Play video and audio with playlists, subtitles, picture-in-picture, an equalizer, a visualizer, snapshots, bookmarks, and a sleep timer — every control reachable by keyboard and announced by your screen reader.

Does it support subtitles?

Yes. Subtitles can be loaded and their size and colour adjusted for comfortable reading.

Accessible Calculator

What makes the calculator accessible?

Every key, result, and operation is announced by your screen reader, and you can also type calculations in natural language — for example "what is 15 percent of 200" — instead of hunting for buttons.

Is the source available?

Yes. The installer and a AccessableCalculator-source.zip package are attached to the same GitHub release under the MIT licence.

Does it work on Linux?

Yes, Clipboard History runs on both Windows and Linux.

What are the main shortcuts?

Ctrl + Alt + V opens history, Ctrl + Alt + Shift + V pastes the most recent item, / focuses search, and Enter copies and pastes the selected item.

Nova Voice Assistant

What can Nova do?

Nova is a desktop voice assistant powered by Google Gemini with 40+ PC control actions — open apps, control media, manage files, search the web, and more — plus neural TTS and a floating orb UI.

Do I need a Gemini API key, and is it safe?

The key is optional and only needed for Gemini features. You enter it yourself in Settings; it is stored only on your device and is never shared. Any billing is directly between you and Google.

Can Nova control my PC by voice?

Among Us Accessibility Mod

Which versions of Among Us are supported?

The mod is built for the current PC version of Among Us via BepInEx 6. Because it hooks the game directly, it needs to be updated when the game updates — grab the latest release after any game patch.

Can sighted players use the mod too?

FC 26 & Rocket League Mods

Will using a mod get me banned?

Does the FC 26 mod need a good GPU?

Does the Rocket League mod require Python?

Do the mods work without NVDA?

No. Screen analysis runs entirely on your PC. The mods never capture or transmit your screen, audio, or gameplay to any server.

Troubleshooting

An app won't start or crashes on launch.

Make sure you're on a supported Windows version, install the latest release, and try running as a standard user. If it still fails, open an issue with your Windows version and what happened — a crash log or screenshot helps.

NVDA isn't announcing anything.

Confirm NVDA is running before you launch the app, check the app's settings for speech output, and verify your default voice is configured in NVDA. Most apps fall back to Windows SAPI if NVDA is not present.

The game mod isn't detecting the game.

Run the game and the mod as the same user, ensure the game is the supported version, and for the Rocket League mod confirm Python and the requirements are installed. Re-download the latest release after any game update.

Accessibility & Design

Why is accessibility the focus of these projects?

A lot of mainstream software is frustrating or impossible to use without a mouse or sight. These projects exist to close that gap — screen-reader-friendly apps, audio cues for games, and tools anyone can operate by keyboard or voice.

Are the apps usable entirely without a mouse?

Yes. Every app is built keyboard-first: menus, dialogs, editors, and players are all reachable and operable with the keyboard, and actions are announced as you go.

Can I adjust font size and contrast in the apps?

Yes. Most apps honour your Windows theme and offer larger text and high-contrast display options. On this website, use the accessibility dialog (Alt+A) to set font scaling and reduced motion.

Screen Readers & NVDA

Which screen readers are supported?

NVDA is the primary target and is what the apps are tested with. They also fall back to Windows SAPI speech when NVDA isn't running, so you still get audio feedback with Narrator or no screen reader at all.

Do the apps work with JAWS or Narrator?

NVDA is the main supported reader. Many controls use standard Windows accessibility APIs, so Narrator often works too; JAWS is not specifically tested. If something doesn't announce, let us know via Discord or a GitHub issue.

What if NVDA isn't installed?

The apps speak through NVDA when it's present and otherwise use Windows SAPI. You'll still hear prompts and results — NVDA just gives the richest, most reliable experience.

Website Accessibility

Is this website accessible?

Yes — it ships with skip-to-content links, semantic landmarks, ARIA labels, visible focus states, keyboard navigation, a light/dark theme, and a reduced-motion mode. Headings are used logically so screen readers can jump between sections.

What does the accessibility dialog (Alt+A) do?

Press Alt + A anywhere on the site to open display settings: switch the theme, scale text up or down, and turn on reduced motion. Your choices are saved in your browser's local storage.

How do I switch between light and dark mode?

Use the sun/moon button in the top navigation, or open the accessibility dialog with Alt + A. The choice is remembered on your device.

Voice Assistant Deep Dive

Can Nova work fully offline?

The on-device command detection and PC-control actions work without the internet. The Gemini-powered natural-language understanding needs an internet connection and your API key; without it, Nova falls back to built-in command matching.

Does Nova record my microphone continuously?

No. Nova listens only when you activate it (for example, with its wake command or a shortcut). Audio is processed for the current request and is not streamed to Demon of Fire.

Which permissions can I toggle in Nova?

You can enable or disable individual capability groups — opening apps, controlling media, managing files, web search, system actions, and more — so Nova only does what you're comfortable with.

Download Safety & Verification

How do I know a download is safe and untampered?

Every release is published on the project's official GitHub repository, and the source code is public so you can review or build it yourself. Prefer the "Releases" links on this site, which point to github.com/demon-of-fire.

Why aren't the installers code-signed?

Code-signing certificates cost money that a small open-source project doesn't have. That's why Windows may show a SmartScreen warning on first run — it does not mean the file is unsafe. The open-source code lets you verify exactly what you're running.

Can I build an app from source instead of downloading?

Yes. Each repository includes the source and build instructions. Building yourself is the most verifiable option if you want to be certain of what's running.

Data & Accounts

Do you store my data in the cloud?

No. The apps process and store everything on your own device. There is no cloud account and nothing is uploaded to Demon of Fire. The only data that may leave your device is text you send to Google Gemini when you opt into those features.

Can I sync settings across devices?

Not automatically — settings live on the device where the app is installed. You can copy an app's data folder to another machine if you want to carry settings over.

How do I delete all my data?

Getting Started

I'm new — where do I start?

Pick the app that matches what you want to do. If you're a gamer, start with a mod (Among Us, FC 26, or Rocket League). If you want everyday tools, try Access Overlay or the Accessible Calculator. Everything is free — just download and run it.

What's the difference between an app and a mod?

Apps are standalone programs (recorders, players, calculators). Mods attach to an existing game to add accessibility cues. Both are free and open source; mods just require the game to be installed.

Do I need to install anything else first?

Usually no — installers bundle what they need. The only exception is the Rocket League mod, which needs Python 3.10+ and a pip install -r requirements.txt. Each release's README lists any prerequisites.

How do I get notified of new releases?

Subscribe to the Atom feed, "Watch" a repository on GitHub, or join the Discord server where releases are announced.

More Troubleshooting

Windows blocked the installer (SmartScreen).

Click "More info" then "Run anyway". As an alternative, right-click the file, choose Properties, and tick "Unblock" before running. This is normal for unsigned independent software.

Nova isn't hearing my microphone.

Check Windows privacy settings and grant the app microphone access, then test the mic in the app's settings. The wake phrase is processed locally, so no internet is required for activation.

Transcription or AI is slow.

Use a smaller Whisper model in Recorder settings, close heavy programs, and ensure your machine meets the recommended specs. Gemini features depend on your internet speed.

The website looks broken in my browser.

Make sure JavaScript is enabled and you're on a current browser (Chrome, Edge, Firefox, or Safari). Try a hard refresh (Ctrl/Cmd+Shift+R) to clear cached files.

How do I report a broken link or typo?

Open an issue on GitHub or post in the Discord server. A link to the page and what's wrong is the most helpful report.

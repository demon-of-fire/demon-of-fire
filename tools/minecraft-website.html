Minecraft Website

Web · JavaScript

A Minecraft fan website project — a fun side build exploring game guides and community pages, with a complete reference wiki.

Web PWA WCAG 2.1 AA

About

A comprehensive Minecraft reference covering every version from Classic to 1.21.1+: crafting recipes with visual grid layouts, a complete item database, mob drop rates, a commands reference, and a growing set of interactive tools.

Features

  • Crafting Recipes — every recipe with visual grid layouts, filterable by category and type
  • Item Database — complete item properties and rarities
  • Mob Drops — exact drop rates and conditions for every mob
  • Commands Reference — full syntax and examples
  • Interactive Tools — nether and XP calculators, enchantment checker, brewing guide, villager trading, mob spawning, and more
  • Compare Items — side-by-side stat comparison
  • Accessible — full keyboard navigation, screen reader optimized, high contrast (WCAG AAA), skip links, and keyboard shortcuts (/ to search)
